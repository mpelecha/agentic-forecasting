# CFM Agent v5.0

CFM Agent v5.0 is a clean, isolated release derived from `cfm_agent_v_4_4_1_revised_evidence_policy`. The revised baseline already implements the Component #9 rule allowing a claim to select all or a proper non-empty subset of source IDs associated with its cited accepted summaries. Only selected, mechanically resolved sources and their normalized publishers count toward evidence tiers.

`ARCHITECTURE.md` is the authoritative design contract.

## Scope of v5.0

- Isolate the package under `cfm_agent_v_5_0` and rename version-specific identifiers to v50.
- Preserve the revised Component #9 implementation without behavioral alteration.
- Add deterministic policy and March 2 regression coverage.
- Add authoritative architecture and release documentation.
- Remove generated bytecode and the commented historical policy block.
- Regenerate and verify the package manifest.

## Preserved behavior

- Eleven-component architecture.
- ARIMA, Kalman, LightGBM, and equal-weight ensemble with 1,000 samples.
- Exactly one successful numerical-suite run and one successful four-query research run per workflow.
- Main-verifier-cleaned summaries as active evidence.
- Evidence thresholds, novelty gates, action caps, conflict handling, and narrowing rule.
- Component #10 transformation parameters and exact-neutral reproduction.
- Audit-only Source Validator and Claim-Support Verifier isolation.
- Ensemble-locked control.
