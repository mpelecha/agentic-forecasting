## Installation

Copy `cfm_agent_v_5_2` into `implementations/energy_oil_forecasting/` as a new sibling package. Do not modify or replace shared `main`, v5.0, or any earlier CFM package. Verify `MANIFEST.sha256`, run the offline checks in `README.md`, restart the Python process, and instantiate fresh `CfmV52Settings`, configuration, and predictor objects.
